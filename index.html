03
הכנת סביבת PowerShell (EXO V3)
התקנה, הגדרה והתחברות למודול Exchange Online Management
ℹ️
ב-Windows PowerShell רגיל אין את הפקודה Connect-ExchangeOnline — היא מגיעה רק אחרי התקנת מודול EXO V3.
א
הרשאת הרצת סקריפטים
מאפשר הרצת מודולים מ-PowerShell Gallery
PowerShell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
ב
התקנת מודול Exchange Online
אם מופיעה שאלה לגבי NuGet — יש לאשר "Yes"
PowerShell
Install-Module -Name ExchangeOnlineManagement
# או בקיצור:
Install-Module ExchangeOnlineManagement
ג
טעינה והתחברות (Import & Connect)
טען את המודול ואז התחבר לחשבון האדמין — ענה YES לכל ההנחיות
PowerShell
# טעינת המודול
Import-Module ExchangeOnlineManagement

# התחברות — חלון GUI יקפוץ
Connect-ExchangeOnline
🖥️
חלון GUI יקפוץ — יש להתחבר לחשבון האדמין של Microsoft שינהל את החדרים.
ד
בדיקת תקינות ההתקנה
PowerShell
Get-Module ExchangeOnlineManagement -ListAvailable
04
ניהול רשימות חדרים (Room Lists)
יצירה, שיוך, בקרה — כל הפקודות במקום אחד
📌
Room List נוצרת רק דרך PowerShell — לא דרך ה-Admin Center.
Outlook ו-Teams מציגים רק חדרים שנמצאים בתוך Room List. חדר שלא שויך — לא יופיע.

א. יצירת Room List חדשה

לאחר התחברות ל-Exchange Online PowerShell:

PowerShell
# יצירת רשימת חדרים בשם IL-Rooms
New-DistributionGroup -Name "IL-Rooms" -RoomList

ב. הוספת חדר לרשימה

נניח שהחדר נקרא NewRoom@domain.com ושם הרשימה IL-Rooms:

PowerShell
Add-DistributionGroupMember -Identity "IL-Rooms" -Member "NewRoom@domain.com"
⏱️
אחרי יצירת חדר חדש, ל-Outlook ול-Teams לוקח 10–30 דקות עד שהחדר מופיע בחיפוש.

ג. פקודות בקרה וניהול רשימות

PowerShell — בקרה וניהול
# הצגת כל Room Lists קיימות
Get-DistributionGroup | where {$_.RecipientTypeDetails -eq "RoomList"}

# הצגת חדרים בתוך רשימה
Get-DistributionGroupMember -Identity "IL-Rooms"

# הסרת חדר מרשימה
Remove-DistributionGroupMember -Identity "IL-Rooms" -Member "RoomName@domain.com"

הגדרות הגורמות לבעיה

הגדרהברירת מחדלהשפעה
DeleteSubjectTrueמוחק את שם הפגישה ומחליף בשם המארגן
AddOrganizerToSubjectTrueמוסיף שם המארגן כנושא הפגישה
RemovePrivatePropertyTrueמסיר מאפייני פרטיות של הפגישה
1
בדיקת ההגדרות הנוכחיות של החדר
הרץ את הפקודה הבאה — החלף את כתובת המייל בכתובת החדר שלך:
PowerShell
Get-CalendarProcessing -Identity NewRoom@domain.com | fl DeleteSubject,AddOrganizerToSubject,RemovePrivateProperty
⚠️ שים לב: יש להחליף את NewRoom@domain.com בכתובת המייל של החדר שלך כפי שהוגדרה בפורטל הניהול.

אם החדר מציג שם מארגן — תראה:

תוצאה צפויה לפני תיקון
DeleteSubject             : True
AddOrganizerToSubject     : True
RemovePrivateProperty     : True
2
פקודת התיקון המלאה
פקודה זו מכבה את כל מנגנוני ההסתרה והפרטיות שמונעים את הצגת הנושא:
PowerShell — תיקון מלא
Set-CalendarProcessing -Identity NewRoom@domain.com -DeleteSubject $False -AddOrganizerToSubject $False -RemovePrivateProperty $False -OrganizerInfo $False -DeleteComments $False
⚠️ שים לב: יש להחליף את NewRoom@domain.com בכתובת המייל של החדר שלך כפי שהוגדרה בפורטל הניהול.
⏱️
המתן 5–10 דקות — ה-Room Panel יתעדכן אוטומטית.
3
וידוא הצלחה
PowerShell — בדיקה
Get-CalendarProcessing NewRoom@domain.com | fl DeleteSubject,AddOrganizerToSubject
⚠️ שים לב: יש להחליף את NewRoom@domain.com בכתובת המייל של החדר שלך כפי שהוגדרה בפורטל הניהול.
תוצאה רצויה לאחר תיקון
DeleteSubject             : False
AddOrganizerToSubject     : False
✅
שם הפגישה האמיתי
הפאנל יציג את שם הפגישה במקום שם המארגן
✅
Outlook / Teams
שם הפגישה יוצג גם בלוח השנה של החדר
⚡
פתרון מתקדם — אם הבעיה נמשכת
כאשר ה-Calendar Processing עודכן אבל הפאנל עדיין לא תקין

אם הגדרות ה-Calendar Processing עודכנו אבל ה-Room Panel עדיין מציג את שם המארגן, יש לעבור על הצעדים הבאים:

1
לוודא שההגדרות באמת עודכנו
PowerShell

הרץ שוב את הפקודה — התוצאה חייבת להיות False לכולם:

PowerShell
Get-CalendarProcessing -Identity NewRoom@domain.com | fl DeleteSubject,AddOrganizerToSubject,RemovePrivateProperty
⚠️ שים לב: יש להחליף את NewRoom@domain.com בכתובת המייל של החדר שלך כפי שהוגדרה בפורטל הניהול.
❌
אם אחד מהם עדיין True — השינוי לא הוחל. יש להריץ שוב את פקודת Set.
תוצאה חייבת להיות
DeleteSubject             : False
AddOrganizerToSubject     : False
RemovePrivateProperty     : False
2
לוודא שאין Override נוסף
מתקדם

יש עוד שתי הגדרות שפחות מוכרות, אבל אם הן מופעלות — הן ממשיכות להסתיר את שם הפגישה:

הגדרהאם True — ההשפעה
OrganizerInfoהחדר עדיין מציג שם מארגן
DeleteCommentsלפעמים משפיע על תצוגת הנושא
PowerShell — בדיקה
Get-CalendarProcessing -Identity NewRoom@domain.com | fl OrganizerInfo,DeleteComments
⚠️ שים לב: יש להחליף את NewRoom@domain.com בכתובת המייל של החדר שלך כפי שהוגדרה בפורטל הניהול.
PowerShell — תיקון
Set-CalendarProcessing -Identity NewRoom@domain.com -OrganizerInfo $False -DeleteComments $False
⚠️ שים לב: יש להחליף את NewRoom@domain.com בכתובת המייל של החדר שלך כפי שהוגדרה בפורטל הניהול.
3
האם הפגישה נוצרה לפני שינוי ההגדרות?
קריטי
⚠️
פגישות שנוצרו לפני שינוי ההגדרות לא מתעדכנות אוטומטית. ה-Room Panel ימשיך להציג שם מארגן עבורן.

כדי לבדוק:

1.מחק פגישה קיימת
2.צור פגישה חדשה לגמרי
3.בדוק אם הפאנל מציג את שם הפגישה החדש
✅
אם הפגישה החדשה מוצגת נכון → הבעיה הייתה בפגישות ישנות בלבד.
4
לוודא שה-Room Panel לא שומר Cache
Yealink

פאנלים של Yealink שומרים Cache של לוח השנה. יש לבצע:

🔄
הפעלה מחדש של הפאנל
🔌
ניתוק וחיבור מחדש לחשבון החדר
⏳
המתנה של 5–10 דקות
5
לוודא שהחדר לא מוגדר כ-"Private Meeting Mode"
Teams Admin

יש הגדרה ב-Teams Admin Center שיכולה לגרום לפאנל להציג שם מארגן בלבד — ללא קשר להגדרות Exchange.

📋 סיכום פקודות PowerShell — Quick Reference
PowerShell — כל הפקודות 
# ══════════════════════════════════════
# התחברות
# ══════════════════════════════════════
Connect-ExchangeOnline

# ══════════════════════════════════════
# ניהול Room Lists
# ══════════════════════════════════════

# יצירת Room List
New-DistributionGroup -Name "IL-Rooms" -RoomList

# הוספת חדר לרשימה
Add-DistributionGroupMember -Identity "IL-Rooms" -Member "NewRoom@domain.com"

# הצגת כל ה-Room Lists
Get-DistributionGroup | where {$_.RecipientTypeDetails -eq "RoomList"}

# הצגת חדרים ברשימה
Get-DistributionGroupMember -Identity "IL-Rooms"

# הסרת חדר מרשימה
Remove-DistributionGroupMember -Identity "IL-Rooms" -Member "NewRoom@domain.com"

# ══════════════════════════════════════
# Calendar Processing — בדיקה ותיקון
# ══════════════════════════════════════

# בדיקת Calendar Processing
Get-CalendarProcessing -Identity room@domain.com | fl DeleteSubject,AddOrganizerToSubject,RemovePrivateProperty,OrganizerInfo,DeleteComments

# תיקון תצוגת שם פגישה
Set-CalendarProcessing -Identity room@domain.com -DeleteSubject $False -AddOrganizerToSubject $False -RemovePrivateProperty $False -OrganizerInfo $False -DeleteComments $False
❗ שים לב: יש להחליף את המשתנים (מסומנים בירוק) בפרטיך הרלוונטים.
📝
תזכורות זמנים:
• שינוי Calendar Processing → המתן 5–10 דקות
• חדר חדש / הוספה לרשימה → המתן 10–30 דקות להופעה ב-Outlook/Teams
